# SS-06A: offline save-contract scenarios

These are synthetic assertions supplied to a pure evaluator. No storage operation,
real policy decision, authenticated approval, or successful save receipt occurs.
A matching fixture shows what evidence must be checked; it is not proof of persistence.

The demo reuses the earlier catalog guide and its explicit source/AI limitations.
It creates no actual nurse's portfolio and reads no browser interpretations or reflections.

From the repository root: `python scripts/portfolio_contract_demo.py --output /tmp/portfolio-contract-review`.
Only the explicitly requested development report files are created. This command does
not install or connect a portfolio store. The core assessor itself performs no IO.
