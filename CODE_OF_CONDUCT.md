# Code of Conduct

We are building safety-critical healthcare infrastructure. We expect a
professional, respectful, and inclusive environment.

- Be respectful and constructive. Assume good faith.
- No harassment, discrimination, or personal attacks.
- Prioritize patient safety and human dignity in all technical decisions.
- Disagree on substance; document decisions via RFCs.

Report concerns to **conduct@florence-x.example**. This project follows the spirit
of the Contributor Covenant v2.1.
